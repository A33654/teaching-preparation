## 1. 核心实体 → 代码映射

实体名来自 PRD §5.1，实现名来自代码。**执行时请使用右侧字段名/端点**。

| PRD 实体 | 实现载体 | 关键说明 / 偏差 |
|---|---|---|
| Assignment（作业） | `Homework` 表 | 状态枚举 `HomeworkStatus`：`draft / published / closed`；⚠ `closed` 无接口入口（§4.4） |
| AssignmentQuestion | `HomeworkQuestion`，**JSON 数组**存于 `Homework.questions` | 非独立表；字段含 `score`（满分，默认 5）、`knowledge_point_ids`、`options`、`correct_option`、`answers`、`reference_answer` |
| Submission（提交记录） | `Submission` 表 | **仅存 `student_id_hash`**，无明文学号列；`answers` 为 JSON；⚠ 无 `superseded` 字段（PRD §7④ 未落地） |
| GradingItem（单题批改项） | `SubmissionGrade` 表（一题一行） | 状态 `QuestionGradeStatus`：`pending / auto_graded / finalized`；⚠ 无 `ai_unavailable` 字段（PRD §7① 未落地） |
| MistakeFeedback（误区回流） | **无独立表** | ❌ **PRD §5.1 偏差**：直接由 `app/grading/backflow.py` 写 Neo4j `Misconception` 节点，无 `status` 三态、无驳回、无审计留痕 → §8 RK-02 / R-2 |

### 2.3 不需要关注的地方（读到这里即可停止探索）

- `Submission.status` 除 `submitted/graded` 无其它值，**不要设计"已归档/已退回"用例**
- `GradingItem.status = pending` 在正向流程中**不会出现**（创建即置 `auto_graded`），仅做理论断言

## 4. 状态机：PRD 期望 vs 代码实现

### 4.1 Assignment（作业）

**PRD §4 期望**：`草稿 → 已发布 → 收集中 → 已截止 → 已批改完成`

**代码实现**：
```
draft ──publish──> published
  ^                     │
  └── 初始态             └── update(PUT) ──> 400 仅草稿态可编辑
closed ── ⚠ 枚举存在但无任何接口可到达
```

| PRD 状态 | 代码对应 | 结论 |
|---|---|---|
| 草稿 | `draft` | ✅ 一致 |
| 已发布 | `published` | ✅ 一致 |
| 收集中 | — | ⚠ 无独立状态，以 `published` 兼任（可接受，需产品确认） |
| 已截止 | `closed` | ❌ **不可达**（SM-10 / EXL-06） |
| 已批改完成 | — | ❌ 无对应状态；目前以"所有 Submission 均 graded"隐含表达 |

### 4.2 Submission（提交）

**PRD §4 期望**：`未提交 → 已提交 → AI 批改中 → 待教师复核 → 已确认`

**代码实现**：
```
（无）──simulate-submit──> submitted ──grade──> graded
```

| PRD 状态 | 代码对应 | 结论 |
|---|---|---|
| 已提交 | `submitted` | ✅ 一致 |
| AI 批改中 | — | ⚠ 无中间态；判分为同步短事务，等价于瞬时态（可接受） |
| 待教师复核 | `graded` | ✅ 语义对齐（判完即待复核） |
| 已确认 | — | ⚠ 无 Submission 级终态，仅在 `SubmissionGrade.finalized` 逐题表达 → 见 SM-14 |

### 4.3 GradingItem（单题批改项）

**PRD §4 期望**：`待 AI → AI 建议(客观已定/主观建议) → 教师已确认 / 教师已改`

```
pending ──grade──> auto_graded ──finalize(confirm=true)──> finalized
                        │                                      │
                        └── 重判：覆盖重算                └── 重判：保留，不覆盖（409/幂等）
```

| PRD 状态 | 代码对应 | 结论 |
|---|---|---|
| 待 AI | `pending` | ⚠ 创建即跳过，实际不落地（SM-11） |
| AI 建议 | `auto_graded` | ✅ 一致 |
| 教师已确认 / 已改 | `finalized` | ⚠ PRD 区分两态，代码合并为 `finalized`（未记"是否采纳" → 无法算采纳率，见 R-8） |

### 4.4 差异汇总（测试重点）

| ID | 差异 | 验证用例 |
|---|---|---|
| SM-10 | Assignment 无法进入 `closed` | SM-10 / EXL-06 |
| SM-14 | Submission 无"全部题终评 → 已确认"聚合态 | 手工核对：全部 `finalized` 后 `submission.status` 仍为 `graded` |
| R-8 | `finalized` 不区分采纳/改分，PRD §1.3"误区回流教师采纳率"无法统计 | EVT-02（缺口） |
